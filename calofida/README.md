# ليموزين كالوفيدا — النسخة الجديدة (Vue 3 + Vite)

تطبيق إدارة أسطول سيارات (عربي RTL، أوفلاين، بيانات محلية في IndexedDB). بديل لملف `limousine-app.html` القديم.

## التشغيل والبناء

```bash
npm install
npm run dev       # تطوير على http://localhost:5173
npm run build     # يطلّع ملف واحد: dist/index.html (فيه الكود والخطوط ومكتبة Excel)
npm run preview   # تجربة النسخة المبنية على http://localhost:4173
```

الناتج `dist/index.html` ملف واحد مستقل: مفيش أي اتصال بالإنترنت (الخطوط متضمّنة جواه).

## نقل البيانات من النسخة القديمة

1. في النسخة **القديمة**: الأدمن ← الإعدادات ← **تصدير نسخة احتياطية (JSON)**.
2. افتح النسخة الجديدة، وأنشئ أول حساب (شاشة أول تشغيل).
3. الأدمن ← الإعدادات ← **استيراد نسخة** واختار الملف.

ملاحظات:
- الاستيراد بيقبل ملفات النسخة القديمة. الأقسام اللي مش موجودة في الملف (زي المستخدمين ومواعيد المطار في النسخ القديمة) بتفضل زي ما هي.
- النسخة القديمة **ما كانتش بتصدّر المستخدمين**، فالحسابات لازم تتعمل من جديد (الأدمن ← الإعدادات ← المستخدمين والصلاحيات).
- أسماء قاعدة البيانات والـ stores والحقول هي نفسها بتاعة القديم (`limoCalofidaDB` إصدار 4).
- ترحيل `localStorage` القديم (`limo_*_v1` من قبل IndexedDB) **ما اتنقلش**. لو عندك بيانات بالشكل ده، صدّرها الأول من النسخة القديمة.

## ملاحظات مهمة

- **ملف النسخة الاحتياطية بيحتوي على بيانات الدخول** (hash لكلمات المرور، و salt، والإجابات الأمنية كنص عادي). احفظه في مكان آمن.
- كلمات المرور بتتخزن SHA-256 + salt. الحسابات القديمة (نص عادي) بتتحوّل تلقائيًا أول مرة تسجّل دخول. ده تنظيم للاستخدام المشترك على جهاز واحد، مش حماية أمنية قوية.
- شغّل التطبيق في **تاب واحد**. تاب قديم مفتوح ممكن يرجّع سجلًا اتمسح من تاب تاني لأنه شايل نسخته في الذاكرة.
- الحساب البنكي في لوحة التحكم = كل الإيرادات − كل المصاريف، ومبيتأثرش بالفلاتر.

## هيكل الكود

```
src/
  db/idb.js            طبقة IndexedDB (نفس الاسم والإصدار والـ stores)
  stores/              Pinia: auth, theme, ops, collections (cars, drivers, maints, tasks, airport, ...)
  utils/               helpers (تواريخ/فلوس), ops (حسابات الصف), backup, excel, crypto, print
  components/          Modal, MultiSelect, FilterClear, ExpiryBadge, PerfChart, OpsRow, AppHeader
  views/               Dashboard, DailyOps, Fleet, Maintenance, Tasks, Airport, Admin (+ admin/*), Login
  fonts.css            خطوط woff2 متضمّنة (مولّدة من @fontsource)
```
